离线使用说明

本文件已包含轻量识别模型、运行组件、示例图片和全部绘图音乐功能。双击用最新版 Edge 或 Chrome 打开即可；不需要安装、不需要启动本地服务，也不需要联网。可直接把整个 HTML 文件复制给朋友。图片只在本机处理。

完整精度模型未包含在此离线包中；内置轻量模型与网页版默认档相同。首次打开文件及识别大图可能稍慢。保留页面打开，等待完成即可。
