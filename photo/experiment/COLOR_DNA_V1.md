# Color DNA v1.0 · 0609.docx 实现记录

## 输入与真实性
颜色从原始彩色图片提取，几何从线稿提取，两路汇入 Progressive 编曲。主库目前只有 sample5 有 source_photo_manifest.json 验证过的彩色原图；其余样本显示“未提供已核实的彩色原图”，不使用着色回归图提取颜色。上传桥接流程读取 original.png，四种音乐风格均支持色彩版本。黑白/近灰输入通过色度证据门控，自动跳过色彩映射。

## 计算
color_dna.py：RGB 转 HSV 的色相用于冷暖，saturation × value 为有效色度权重，冷暖投影除以有效色度总量，不除以全图像素数。白灰背景不会把冷暖平均稀释到零；也不把每张图片强行拉伸至 ±1。另保存色度证据，低色度输入不报告冷色情绪。
明暗使用 sRGB 线性化后的 Rec.709 相对亮度均值；对比度使用亮度 P95−P5；饱和度使用 HSV 均值。绿色是色相标签，不等同冷/暖、快乐/悲伤。暗部图片的线性亮度数值通常低于肉眼直觉的 HSV 明度。

## 音乐实际变化
- 几何仍控制主题采样点、曲率身份、重复节奏、方向性组织。
- 明暗产生小范围音区偏移，在当前曲风音阶内重新量化，不整体升降八度；主题相邻跳进限制七个半音。
- 冷暖以有界幅度偏向六度/九度和声，接近中性时影响趋于零，不设置暖色=大调、冷色=小调的硬切换。
- 饱和度调节连奏长度、伴奏与弦乐的混合比例；曲风指定的乐器家族不变。
- 对比度调节音符的局部重音/弱拍力度差，不直接调节整曲总音量。
- 使用 0 / .35 / .75 / 1 的色彩表达强度；音符音高、音区与配器本身是离散音乐事件，因此参数连续不等于音频可连续变形。界面切换预渲染版本，保持当前位置继续播放。
- 保留最多六音并发、36 秒收束、既有四阶段与原图回归。

## 验证与边界
新增 test_color_dna.py 三项：已知色相与白底归一化、四类以上图片固定几何 A/B 音高/时值差异、原有曲风/六音并发/时长限制。黑白输入开启关闭保持同样音乐。真实主题 source 与采样点在 A/B 中保留。
另有 test_progressive_arrangement.py 五项、test_studio.py 十项、渐显规划 51 项检查通过；上传桥接代码语法检查通过，但本轮没有重新跑完整上传图生图流程。
浏览器验证选择器、原图标签、A/B 播放位置保持、无原图禁用与展演布局。没有以人的听觉对每份成品做主观审美打分；自动检查不代表专业音色或艺术情绪识别能力。颜色映射是可解释创作规则，不是经过实验证实的普遍色彩心理学结论。
