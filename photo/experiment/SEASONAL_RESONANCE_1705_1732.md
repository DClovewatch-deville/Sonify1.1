# 四时共鸣核心改动

依据 1705&1732 Color DNA.docx 两段建议及嵌入音乐矩阵，采用轻量动态氛围和季节编排，不接入图生视频。

## 三个系统的边界

- Geometry DNA：保留真实几何取样点，生成图像身份动机。
- Color DNA：输入图片色彩和用户曲风，决定表达色彩。
- Seasonal Arrangement：同一身份的四季演绎，改变密度、时值、装饰、音区和空间感。

普通 Progressive、Blueprint、Soul 保持现有编曲。新增身份算法目前应用于四时共鸣，避免重写其它模式。不同图像的身份主题不能共用固定 MIDI，季节也不能取代图像身份。

## 已落实

`seasonal_rules.py` 集中定义四季的调色、相对音区、密度、连奏、主题进入小节、回应节奏、上行装饰、视觉粒子、光照和空间系数。试听、滑条和自动流转读取同一份状态配置。

`identity_motif.py` 从主结构与空间上分离的对比路径提取真实顶点，保留绝对画面高度和横向位置，避免将所有斜屋檐都归一化成相似下行主题。取样位移还影响节奏权重。没有随机音符种子；音符仍能追溯到原几何来源与父事件。

`progressive_arrangement.py` 增加可选的 identity_mode、season；默认调用保持原行为。春有短句和少量上行装饰，夏有更多主题进入和回应，秋有较低音区和较舒展时值，冬减少主题进入及回应、保留延音。硬性复音上限 6。各曲风的乐器家族保留。

`ui/living_color.js` 加入花瓣/落叶/雪点/微光、夏日柔光束、冬季薄雾与边缘霜感。按照片实际显示范围裁剪，不遮盖外围 UI。用户可关闭特效，或选择中性、自然户外、建筑户外、室内人像场景。默认中性氛围，不宣称自动语义分割。真正的叶片和雪点需选择相应户外场景。支持减少动态效果偏好。

动画预览无需先播放音乐。统一滑条决定相邻两季的图像、粒子、色彩滤波与混响比例。自动流转在 8/16/24 秒换季，各用约 2 秒做视觉过渡；手动音乐变化排到下一处约 4 秒乐句边界。主题在这些边界前收束，避免简单中途截断。通过短暂淡出/淡入控制切换，不声称实时连续插值调式。

增加可试听的 **听图像主题 无季节**，以 8 秒真实旋律展示图片身份，便于跨图比较。原有暖/冷/暗部分轨试听补偿保留。

## 验证证据

三张几何输入的中性 Nature 主题：

| 输入 | 基础主题 MIDI | 相对音程 |
|---|---|---|
| 示例亭子 sample5 | 76 76 76 69 67 64 | 0 0 −7 −2 −3 |
| 上传宽幅建筑 8FB4B1 | 74 81 74 79 | +7 −7 +5 |
| 上传山水 15EAD2 | 79 81 81 81 74 69 72 76 | +2 0 0 −7 −5 +3 +4 |

测试比较的是相对音程与实际顶点，不是仅比较移调后的绝对音高。数据在 dist/seasonal-identity-audit.json。

24 项 Python 测试通过，覆盖真实来源、同图跨季身份、不同图的相对音程、四曲风、音乐事件差异、复音、音频时长/RMS/峰值及原模式回归。13 项季节时序断言与 51 项 Progressive 计划断言通过。主案例夏季事件比春季多，冬季比秋季少。这里只证明结构差异，不等同人类听觉验收。

## 明确未实现

- 没有识别真实树枝并让新芽沿枝生长，没有物体重绘或地面积雪重构。
- 四季仍是同一几何身份的四份真实预生成编曲，未实现完整实时作曲。
- 连续版本保留共享 120 BPM。文档 88–98/100–112/78–90/60–74 BPM 是调参参考，尚未做四种独立速度；当前通过节奏密度、进入时刻和时值改变呼吸。
- 混响采用同一确定性卷积响应和不同湿声比例，尚非四种分别标定衰减时间的房间模型。
- 秋季主要通过中音区、时值和织体表达回落，尚未全面实现专门的下行句尾发展算法。
- 不保证任意图片都得到唯一悦耳旋律。尚需用户试听四季辨识度、跨图身份与连接自然度。

## 更新现有作品

`python living_color.py` 生成当前彩色作品状态及身份音频，使用 season-v11 文件名，完成单个作品后才原子发布 JSON。

`python publish_color_ui.py` 同步界面；UI revision=color43。

新上传由 bridge 的原有引擎快照机制调用最新模块，无额外模型调用。参数更改后应重新渲染状态音频，不应只更新界面数字。
