# Sonify Plan A 统一入口

在工作区根目录双击“启动Sonify.cmd”，然后访问 http://127.0.0.1:8781/ 。总首页与管理台仅开放本机；同时启用原有 8782 手机配对上传服务，保留 Plan A 扫码输入。手机与电脑需连接可互访的同一 Wi-Fi 或热点。

首页三个分区为 MusicPhoto、MusicPaint、MusicLab。

| 路径 | 当前内容 |
| --- | --- |
| `/` | Sonify 统一首页 |
| `/experience` | 现有 MusicPhoto 生成体验，品牌链接返回首页 |
| `/capture` | 原图片上传页面，保留原有功能 |
| `/paint` | MusicPaint 桌面演示说明，待交付 HTML 后替换 |
| `/musiclab` | MusicLab 入口占位，等待确认实际交付 |
| `/host` | 原扫码接待控制台 |
| `/circle` | 圆绘 V2.5 独立入口，未擅自归入 MusicLab |

MusicLab 是校园地标、风景及公开摄影作品的音乐作品集，不是圆绘音乐，也不是泛指音乐实验工具。圆绘仅为独立 Demo，不计入三个产品分区。圆绘网页从组员 V2.5 压缩包提取到 `modules/circle/index.html`，原始交付未修改。

## 动态开发时的接入约定

首页固定链接到 `/capture`、`/paint`、`/musiclab`。MusicPhoto 分区进入原上传首页，再由原页面进入 `/experience` 完整生成体验。子页面仍在开发不妨碍入口集成，内部升级后仍保持这些对外地址。MusicPhoto 当前可访问不代表最终版本已冻结。

每位组员独立维护自己的项目副本，交付完整资源文件夹和入口说明；整合负责人将当前可演示版本接到固定地址。新版本先在副本验证，再替换当前版本；保留上一个可运行文件夹用于回退。不要直接覆盖正在演示使用的文件。

模块文件保持原有内部目录，避免将各模块 JavaScript 和样式合并到同一页。接入时检查根路径资源引用和后端地址。每轮仅验收：首页进入、模块实际操作、返回首页、刷新后资源正常。模块间传图和共享数据留待明确接口后独立接入。

未交付的网页使用明确标注的筹备页；收到交付后替换路由对应内容，不以占位页作为接入完成。

MusicPaint 与 MusicLab 目前仅有入口页，尚未完成子功能接入。需要提供各自完整 HTML/资源文件夹、入口文件以及后端启动方式。不要用占位页面作为功能接入验收结果。

目前不改 MusicPhoto 音乐引擎、任务队列和手机访客权限。原首页上传页面保留在 `/capture`。后续首页外观在 `web/sonify.html` 和 `web/sonify.css` 修改。
