# MusicLab 首版评估与运行记录

GPT 建议的定位合理：Campus Symphony 优先，复用 Photo 引擎，以浏览和聆听为中心。现有项目使用 Python HTTP 服务与原生 HTML/CSS/JS，首版沿用现有结构。

已完成四张校园专辑：图书馆西立面、校园标志塔、校园长廊与标志塔、校园主轴全景。每张照片均逐项核验 Wikimedia Commons 的 CC BY-SA 4.0 许可，并保存作者、来源页面、许可链接及缩放说明。

运行入口：http://127.0.0.1:8783/musiclab 。8781 已有旧服务占用，未中断它。停止预览后可用同一项目 Python 运行 server.py --port 8783。默认只允许本机访问。

生成入口：build_museum.py。复用现有 Photo 的 Canny、结构提取、Blueprint 编排与 SoundFont 渲染，每张照片产生实际 13 秒 WAV、MIDI、图像哈希与引擎哈希。资产位于 web/museum；生成结果可离线浏览。已有文件会复用；修改生成规则后应在新目录生成，避免混用历史证据。

本版每个对象只有一张照片和一个真实音乐版本。尚未实现多视角画册、多种人格编曲、全球探索、跨照片稳定建筑旋律身份。Color DNA 已分析保存，但当前 Blueprint 音频没有使用色彩；页面如实说明。

验证：浏览器确认四张卡片、详情、真实播放、切换后停止；四组图片/WAV/MIDI以及首页、Photo、Paint、Lab、CSS、JS均返回200；四段音频均非静音。音频品质仍建议团队用现场设备试听。

既有 test_intake 的11项测试中10项通过，test_phone_pairing_upload_isolation_and_host_queue 失败。现有 guest_allowed 允许已配对访客访问经自身任务过滤的 /api/host，而测试要求另一访客收到HTTP错误。这处行为未在本次修改，未为通过测试改变手机入口权限。

后续顺序：先试听与策展修整，再为建筑补充有明确许可的不同视角；随后复用 Photo 现有 Progressive 风格产生真实版本；校园主流程稳定后再加入开放授权的全球作品。不要直接采用文档中未核验的图库数量、技术栈或授权断言。

## 第二版更新 2026年10月17日

本轮以实际开发为主，暂不追加产品评分。预览仍在 http://127.0.0.1:8783/musiclab 。刷新页面即可看到新版。

馆藏扩展至12件：原4件校园作品独立归入校园交响，另加入8件经视觉检查的开放许可摄影作品，其中7件在Commons获精选图片认定、1件获优质图片认定。新增原作均下载1920像素预览，详情使用contain保留构图；卡片允许封面裁切并在来源中说明。

分类方法采用人工策展的受控主题、可见画面标签和独立地点字段。主题为校园交响、建筑与空间、山水与自然；画面标签如室内、透视、对称、树林、水面、暮色。它们是人工策展判断，不冒充视觉模型的自动识别。地点依据原始文件标题和说明，有明确依据才填写；来源不明时显示来源未注明拍摄地点，地点不作为进入展厅的必要条件。原始说明、作者、许可、来源类别与质量认定均保存在各作品source.json中。

所有12件作品均已复用Photo引擎生成三种模式：Blueprint、Soul、Progressive。Progressive含东方自然、西洋小型交响、独奏钢琴、弦乐叙事四种编曲，总计72段真实音频及72份对应MIDI。Blueprint和Soul以几何为主；Progressive实际使用原照片Color DNA。使用本地OpenCV结构处理，无额外付费云调用。音频为预生成缓存；不声称跨照片建筑旋律身份已稳定建立。

新增主题筛选、画面标签筛选、全文搜索、浏览器本地收藏、原图与实际结构线稿切换、三模式切换、渐显人格切换、音乐及MIDI下载、来源与映射依据展开。播放器为单实例；用户正在播放时切换模式/人格/作品会载入新版本继续播放，关闭详情停止；不自动在首次打开时播放。

curate_museum.py负责素材核验下载；build_museum_v2.py负责版本化生成；清单为web/museum/albums-v2.json。版本目录依据图像和引擎哈希生成，清单仅在全批次完成、引擎未变化后原子替换，保留旧版。未改动Photo核心源文件或音乐算法。

verify_museum.py检查全部72段音频非静音、未削波、内容哈希互不重复、时长匹配、MIDI头有效、图片输入哈希一致、Soul和Progressive的每个音符source可追溯到该照片路径、Progressive风格及色彩数据一致，所有相关资源HTTP响应与磁盘长度匹配：全部通过。

浏览器实测：主题筛选、搜索、收藏与刷新持久化、真实播放、钢琴人格音频切换、Soul模式切换、Blueprint模式切换、原图/线稿切换均正常。390像素与1280像素断点均检查；手机详情无横向溢出。音乐主观审美与现场外放表现仍需听感评审。

当前资源目录约1.45GB，包含独立声部、混音、编排元数据及缓存证据；页面按用户选择加载单段混音，不会一次下载全部音乐。后续分发包可仅打包清单引用的混音、MIDI和展品资源，将制作声部分离归档。

## 第三版核心交互更新

依据用户2026年10月17日的明确要求，核心定位改为沉浸式声音摄影册；完整需求约定见MUSICLAB_DESIGN.md。

入口从作品筛选列表重构为三册布面画册，校园与其他摄影独立分册；阅读室用跨页照片、纸张中缝、简短策展诗句和页码组织浏览。CSS封面绕书脊展开、纸页翻动与合书动效均接入实际交互；提供目录、键盘、页码与触屏横扫入口。

移除常驻模式分区、技术面板、原生播放器。保留单一真实音频元素，自定义小唱片、进度、音量、静音、可选自动翻阅；来源、音乐版本与下载退到辅助菜单。静心观看可淡出文字及纸张效果。

修复原服务未提供音频字节区段读取而导致的浏览器seekable区间为0的问题。现在Lab音频支持200/206/416，浏览器实测seekable为完整0-36秒范围。新增3项HTTP测试（含多个范围子用例）全部通过。

浏览器确认：开书播放、暂停后翻页不自动播放、实际音轨与当前页一致；自动翻阅由ended触发并在册末停止；声音版本切换、目录跳页、来源查阅和合书停止正常。390x844检查reader宽高均不溢出。首页、Photo、Paint、Lab与页面资源均返回200。

摄影展官方来源线索单独整理为CAMPUS_PHOTOGRAPHY_SOURCES.md，不将未知许可作品直接纳入现有画册。当前仍为12件照片、72个真实音乐版本；本轮重点是阅读与聆听的体验重构。
