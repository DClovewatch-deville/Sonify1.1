# Progressive 嵌入式展演尺寸修复

2026-10-17

原因：内页的 fixed 展演区域被约523px高的iframe限制。控件换行及章节、色彩、音符轨占用空间后，画布被grid剩余高度压缩。开关状态正确不代表尺寸正常，上轮验证遗漏此项。

修复：父页面观察内页展演class，展演时把iframe铺满浏览器；退出、切换作品、重看时清理观察器和父页面状态。展演画布保留至少65dvh/320px高度，空间不足时滚动，控制条置顶。未改动Photo主线或重建音乐、未调用豆包。

浏览器实测：
- 1280×720：旧展演画布约157px，修复后466px，普通模式约382px；展演容器720px且顶端为0。
- 940×1000：展演画布648px。
- 内页退出按钮、内页Esc、焦点位于外层按钮时Esc均可退出，父页面恢复正常尺寸。
- 展演播放、章节跳转及停止可用，退出不重新生成或重置作品。
- JavaScript语法检查通过。
