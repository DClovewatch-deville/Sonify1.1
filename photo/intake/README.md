# Photo 图像入口

独立入口：`http://127.0.0.1:8781`。运行 `start.ps1`，或使用项目 Python 运行 `server.py --port 8781`。默认只监听本机。

## 现场手机扫码上传

关闭本服务旧启动窗口后，双击 `start-event.cmd`（或 `start.ps1 -Share`），在笔记本打开 `http://127.0.0.1:8781/host`。

1. 手机和笔记本连接同一 Wi-Fi 或同一个手机热点。扫码不需要调用云 API。
2. 控制台选择实际使用的 Wi-Fi 地址，将二维码展示给观众。地址选择会保存在 runtime，下次启动时仍存在该地址则复用。
3. 观众扫码 → 相册选图 → 自动缩小至最大 2048 像素并转换为 JPEG → 上传。浏览器无法解码 HEIC 等格式时，请使用 JPG/PNG。
4. 手机显示任务编号，电脑列表自动出现对应图片。图片处理可排队，音乐渲染每次只运行一个，减少小笔记本资源竞争。
5. 工作人员点击对应“打开作品”，在独立窗口中进入现有三模式展示。其他人上传不会自动切换播放内容。

接待控制台使用紧凑布局，并提供全屏按钮，方便 11 寸屏幕。电脑原来的单张上传仍保留；22 张图片批量测试可独立增加，不依赖此现场入口。

电脑控制服务只监听 `127.0.0.1:8781`；手机上传另用 `0.0.0.0:8782`。手机必须先扫描包含随机配对凭证的二维码，兑换 8 小时 HttpOnly / SameSite 会话；手机接口只能访问自身任务及产物，不能列出任务、控制主屏或调用 AI 付费分支。二维码在服务重启后失效。配对凭证不写访问日志。此 HTTP 服务仅用于可信局域网，不应转发公网端口；图片会留存在电脑 runtime，当前没有自动删除。

如果校园 Wi-Fi 阻止设备互访，改用两台设备都连接的手机热点。Windows 防火墙可能需要用户为专用网络允许 Python 的 8782 入站连接，本程序不会关闭防火墙或自行修改规则。不要对公用网络开放所有端口。实际手机的网络可达性仍需要现场扫码确认。

首次在其他电脑使用二维码功能，需安装此目录 requirements.txt 中的 qrcode，或用项目 Python 将其安装至此目录 vendor。当前电脑已安装在独立 vendor，不改全局 Python 环境。二维码按 [python-qrcode 官方用法](https://github.com/lincolnloop/python-qrcode) 本地生成，不将地址发送给第三方二维码网站。

## 已实现

- 上传 JPG/PNG（12 MB 上限、24 MP 解码限制）；纠正 EXIF 方向、透明背景铺白、移除原始元数据并缩放至最大 2048 像素。
- 本地 Canny 结构线稿 → 复用现有确定性几何提取器 → 路径 JSON 与接入清单。
- 独立子进程复用现有 Blueprint、Soul、Progressive 编排和 SoundFont 渲染；每个任务有自己的页面、manifest、音乐与来源映射。原有主线源文件和 `experiment/dist` 产物不会被重建或覆盖。
- 记录引擎源码哈希；生成期间源码发生变化则拒绝发布该次音乐，避免混用开发版本。已有工作区不会随主线继续开发而改变。
- 真实队列、阶段状态、错误提示、任务持久化与刷新恢复。重启后的未完成任务明确标记失败。最多两个并行任务、八个排队/处理中任务。
- AI 展示与结构结果分别记录；艺术分支失败不阻断结构及音乐。图片生成结果不保证与原图/另一线稿对齐，音乐页面使用结构线稿坐标。

## 配置真实 AI（需要用户介入）

复制 `config.example.json` 为此目录的 `config.local.json`，填好后重启服务。配置文件和 runtime 均已忽略，密钥仅从服务进程环境变量读取。

### ComfyUI 结构分支

必须使用专用工作台；本服务拒绝向 8190 端口提交。这里没有安装模型、创建工作流或占用原工作台。

- `comfy_url`：专用实例可访问地址，例如 `http://127.0.0.1:8191`。若模型在台式机上，使用其实际可访问地址。
- `comfy_workflow`：已在专用实例跑通的 API 格式 JSON 路径（相对路径以本目录为基准）。
- `comfy_input_node`：LoadImage 节点 ID。
- `comfy_output_node`：返回 images 的保存图片节点 ID，避免误取中间预览。
- 保留工作流中的提示词、模型、步数和种子；仅替换上传图片输入。预热需要在专用实例执行。
- 上传 → 提交 → 轮询任务历史 → 指定输出节点 → 获取图片。暂未接 WebSocket，界面只展示可确认的阶段，不编造推理百分比。超时不会中断整个远端队列，远端任务可能继续运行。

接口依据：[ComfyUI 官方路由](https://docs.comfy.org/development/comfyui-server/comms_routes)。

### 豆包艺术分支

需要用户开通支持图生图的火山方舟模型、可用额度和密钥。将 `ARK_API_KEY` 配置到启动服务的环境中，`ark_model` 填实际可用模型或 endpoint ID。不要将密钥写入前端或提交到仓库。

`ark_size` 必须满足所选模型要求；示例尺寸不保证适用于所有模型。使用 Base64 输入和输出、本地保存 PNG，保留水印。当前适配器已实现，未付费调用或验证具体账号模型；上线前需实测响应字段、效果和耗时。模型名称与价格不沿用历史文档作为事实。

接口依据：[火山方舟图片生成 API](https://docs.volcengine.com/docs/ark/image-generation-api?lang=zh)。

## 产物和边界

`runtime/<job_id>/` 包含 original / structural / artistic（启用时）、skeleton、geometry.json、handoff.json、job.json、engine-version.json 和独立 workspace。上传内容仅保存在此目录；当前没有自动清理，演示结束后可停止服务并按需清理任务目录。

接入清单有独立 schema，不能直接替换共享 studio manifest。bridge 为每份作品构建独立兼容产物；内部沿用单样例键 sample5 仅用于现有页面兼容，内容完全来自当前任务，job ID 与结构图哈希记录在 payload 中。

`geometry.json` 的 p 前缀 ID 表示筛选后的候选路径；音乐引擎会从同一骨架另行构建完整 b 前缀路径图。音乐音符的 `source` 必须追溯到 `music_payload.contours`，不能直接和候选路径 ID 混用。音乐页面的 JSON 下载包含完整路径与音符关系。

本地轮廓提取是真实传统图像处理，不是 AI 审美素描或可靠语义理解。任意图片的音乐质量仍需试听，不能把无路径或渲染失败声称为成功。当前现有几何算法会忽略边缘 8 像素，并采用候选路径筛选；详情以主线算法为准。

`build_music: false` 可在配置中关闭自动音乐构建，仅验证上传和结构处理。音乐渲染最长 300 秒；超时或失败保留结构结果。详细构建诊断在本地 bridge.log，不通过网页暴露。

验证：在本目录用项目 Python 运行 `-m unittest -v test_intake`。ComfyUI 使用本地协议替身验证，不代表真实模型已联调；云端尚待用户配置后验证。
