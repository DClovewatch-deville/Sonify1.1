# Scroll V3 展示修正

画卷始终显示原始彩色图像，取消全景骨架图与线稿切换。

开启「看见声音来源」后，只在当前实响音符的真实来源路径附近叠加半透明彩色掩膜：金色古筝、青色笛子。默认浓淡 28%，可调 10–50%；音符结束后余晖在 1.2 秒内淡去，不累计覆盖全幅画卷。关闭后恢复纯原画。

保留 5733×1200 解析、36,349 条轮廓及 125,060 个采样点。Soul 为 1,284 个实响音符、11,324 条来源路径；Blueprint 为 4,115 个音符、16,352 条来源路径。解析密度与实际音乐不因展示调整而降低。掩膜是来源轮廓附近的软色带，不宣称语义物体分割。

音乐、乐谱与采样资产不变；本次仅调整 Scroll 展示层。播放器源为 scroll_player.js，由 publish_scroll_player.py 内联到 web/scroll.html。

## 彩线留迹版本

「看见声音来源」默认使用彩线留迹：五声部分色、1.9 画布像素细线、72% 不透明度；仅画已到起音时刻的真实乐谱来源路径，画卷原图不变。即时发声路径更亮。另提供即时彩线及柔光掩膜模式，透明度可调 20–100%。

点击画上彩线按屏幕距离拾取真实路径，选中线变亮，显示来源 ID、对应音符 ID、采样坐标、音高、起音与时值，并可回到该音起处。多次使用的路径展示最近已奏关联；同音汇聚关系明确展示，不伪称数学上的严格一对一。回退进度会重建已奏来源，换音乐版与显示模式会清空旧层。

验证：test_scroll_display.cjs 覆盖未来路径排除、累积、后退清理、重复来源最新音符、即时模式、余晖过期。此更新不改变音频及乐谱资产。

## 原画 / 音符谱卷双层

彩线渲染与说明面板完全解耦：Soul 与 Blueprint 均默认彩线，面板默认关闭，关闭面板不关闭彩线。宽屏打开面板为画卷留出右侧空间；标题支持指针拖动与方向键移动，小屏使用底部说明区。

新增音符谱卷切换：原画渐暗下沉，采样点谱上浮。静态点使用当前实际乐谱每个 contributing_source 的真实 source_point，五声部分色；横向起音、纵向来源高度。多个点可合成同一个实响音符，页面统计分别注明。Soul 1,284 音符 / 13,248 来源采样；Blueprint 4,115 音符 / 22,152 来源采样。可点击点查实际音符。

两个视觉层复用同一 track、cameraProgress 与 audio.currentTime。层切换不修改音源、播放状态或时间，允许播放中切换；更换音乐版本才会载入其对应音源与乐谱，并保留进度。谱层高亮当前实响来源，扫描游标与音频同步。

验证：浏览器确认默认彩线、面板关闭不影响彩线、面板让位、键盘移动，以及播放中切层音源不变且时间连续。10 项 Python 映射/音频/传输检查与显示状态回归通过。

## 可关闭叠加与可辨识轮廓

新增「纯原画 / 恢复彩线」独立开关：关闭全部画面叠加并退出第二层、收起面板，音频状态与时间不变；重新进入也尊重关闭状态。点击轮廓音符卷则主动重新打开映射视图。

第二层改为原画淡墨底图（16% 灰度图）+ 完整提取轮廓 + 实际乐谱来源彩线 + 每个音符一个主采样点。避免把全部汇聚点平铺成静态点云。当前音符完整来源仍同步亮起，点击采样点仍可查合成关联。轮廓底图明确属于视觉上下文，不宣称所有轮廓都在发声。未增加依赖，未改变乐谱或音频。

## 主要轮廓与空格控制修正

第二层底图改用独立 major-contours.png，不再绘制 36,349 条音乐解析路径及整套静态彩线。build_scroll_display.py 对原画缩至 3440×720，双次双边滤波、局部对比、轻度高斯、Canny，再去除小于 55 边缘像素的连通域，保留 1,348 个较长连通结构。原画灰度辅助降至 4.5%。音乐几何、音符和音源未改；当前发声仍使用完整原始来源，静态保留每个音符一个主采样点。

空格键优先处理播放/暂停，避免普通按钮焦点拦截和浏览器原生按钮重复触发；长按不连切。尚未开始时空格可开始。文本编辑、下拉选择及题记对话框保留自身键盘操作。浏览器实测按钮焦点下两次空格得到暂停/继续，第二层状态保持。
